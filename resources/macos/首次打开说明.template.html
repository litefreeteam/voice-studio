安装与首次打开说明

这份说明可以离线阅读。先将声悦安装到“应用程序”，再按需要完成首次打开确认。

1. 拖入“应用程序”

  1. 在 DMG 窗口中，将左侧的声悦图标拖到右侧 Applications 文件夹。
  2. 等待复制完成，然后在 Finder 的应用程序中找到并双击声悦。
  3. 如果系统仅询问“这是从互联网下载的 App，是否确定要打开”，确认来源后点打开。

系统要求：macOS 14 或更高版本。M 系列芯片使用 arm64 安装包，Intel 芯片使用 x64 安装包；可在苹果菜单的“关于本机”中查看芯片或处理器。

2. 如果提示无法验证开发者

当前安装包尚未经过 Apple 公证。macOS 可能显示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”。确认安装包来自你信任的发布渠道后，按以下步骤单独允许声悦：

  1. 先从应用程序双击声悦一次。如果出现阻止打开的提示，关闭该提示。
  2. 打开苹果菜单 → 系统设置 → 隐私与安全性，向下滚动到安全性区域。
  3. 找到提及声悦被阻止打开的提示，点仍要打开。按系统提示使用密码或触控 ID 确认。
  4. 如果系统再次询问，点打开。系统会为这个应用保存例外，之后即可正常打开。
系统设置 → 隐私与安全性 → 安全性 → 声悦 → 仍要打开

跟着截图找到按钮

以下是 Apple 官方的 macOS 中文示例截图，红框和编号标出了点击位置。图中的“示例 App”对应你电脑上的“声悦”。不同 macOS 版本的外观可能略有不同，请按按钮名称操作。

这些步骤只为声悦设置单独的打开例外，无需关闭整个系统的安全保护，也无需运行终端命令。

找不到“仍要打开”？

请先确认声悦已经复制到“应用程序”，再双击尝试打开一次，然后立即返回“隐私与安全性”查看。若电脑由单位或学校管理，相关选项可能由管理员控制。

提示“已损坏”或“将损坏你的电脑”？

这与普通的“无法验证开发者”提示不同。请停止打开，联系安装包提供者核对文件或重新获取安装包。

3. 打开后准备配音

软件打开后，按界面提示完成设备检测、授权和声音资源准备。首次下载运行组件与声音模型需要联网，完成后可以在本机配音。安装 DMG 不会自动下载全部模型。

确认已从“应用程序”正常打开声悦后，可以在 Finder 中推出安装磁盘。下次仍从“应用程序”打开。
