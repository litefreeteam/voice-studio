# 主项目成品导出

主项目「导出成品」将选定范围已生成的配音加工成可交付 ZIP，无需再次生成、加载模型或下载新模型。旧「仅分段」入口保留。

## 操作

1. 完成台词配音后点击「导出成品」。
2. 选择筛选结果、当前章节、选中台词或整个项目。
3. 默认要求全部台词完成且属于当前版本。需要节选时选择「仅已完成台词」，确认跳过数量；未齐全的拆分台词不会只导出一半。
4. 设置音量均衡、可选首尾静音裁剪、句间停顿、原分段备份。
5. 选择保存位置。可查看处理进度、取消、失败后重试。切换项目会取消旧导出，迟到消息不影响新项目。

## 文件

- merged.wav：48 kHz、16-bit 单声道合并音频。
- merged.mp3：合并 MP3。编码可能引入延迟/填充，精确字幕剪辑优先使用 WAV。
- subtitles.srt：以原台词文字和处理后的分段时间生成；不是逐字识别对齐。
- README.txt：包内使用与处理说明。
- report.json：处理设置、音量/峰值、质量提醒、范围及节选信息。
- manifest.json：排序、来源和导出范围信息。
- segments/：可选原始 WAV 备份，逐字节保留，不是处理后的音频。

## 默认与边界

句间停顿默认 350 ms，允许 0–3000 ms。同一句拆分片段之间不追加停顿。

默认开启有效语音帧 RMS 均衡（目标 −20 dBFS、增益最多 ±12 dB），并保留 −1 dBFS PCM 样本峰值保护。关闭均衡仍保留峰值安全衰减。不是 LUFS 或真峰值标准化，不承诺消除已经存在的削波或噪声。静音、原始削波、增益限制、峰值限制、立体声转单声道会报告。

静音裁剪默认关闭，开启后每端最多裁剪 1.5 秒，并保留约 120 ms 缓冲；轻声和呼吸仍应试听确认。

单次最多 5000 段、6 小时；单段最多 30 分钟；源文件累计最多 4 GiB，临时工作预算最多 8 GiB。处理前检查磁盘余量；超限按章节拆分。

原始音频及历史记录不改写。分块重采样与编码避免整段加载。请求 ID 隔离取消，取消当前导出不停止此前配音任务。临时文件采用所有权校验与原子发布。
