# 旧声音复核与童声重做（2026-10-15）

## 处理结果

检查了全部 36 个原有声音，并将后来新增的 6 个声音纳入技术检查，共 42 个。按用户反馈，优先淘汰四个旧童声录音，保留原有名字、标识和头像，换成新生成的童声；另重做亦辰，使青年男声的表达更清朗。总数保持 42。

| 声音 | 本次替换方向 |
| --- | --- |
| 乐乐 | 学龄男童，清亮、活泼、好奇 |
| 小雨 | 学龄女童，清脆、灵动、自然 |
| 豆豆 | 幼童男声，细软、稚嫩、玩具对白 |
| 果果 | 幼童女声，软糯、明亮、自然短句 |
| 亦辰 | 已变声青年男性，清朗中音、轻暖共鸣 |

童声改用儿童日常对白作为试听文案。共生成 17 个候选，综合声学指标、转录结果和声音定位选择 5 个替换录音；没有只对旧声音升调。保留的 16 份较早试听统一音量、清理边缘静音，其余保留原来的声线。

## 避免配新文案时重新变声

五个重做声音增加内置精选样本，样本与列表试听的 MP3 字节、SHA-256 和原话一致。默认开启固定人物声音且使用原描述、原语言时，新角色将这份样本复制为自己的独立定声，再复用它生成新台词，不重新随机设计。重复生成和重启继续使用已保存的定声。

样本经过文件名、大小、SHA-256、采样率、时长与有效人声检查，缺失或损坏时明确报错，不回退为随机人物。文件保存在受校验应用归档的 `backend/voice-*.mp3`，通过原有私有引擎提取流程交给 Python；没有增加外部可编辑的样本路径。

已有角色、作品和定声样本保持原有身份，不强制换声。想让已有角色改用新童声，可重新选择对应声音并确定声音后保存。修改声线描述、切换语言或关闭固定人物声音，继续使用原来的自由设计流程。精选样本沿用录音中的语气；需要不同表达时，可修改描述后重新设计。

## 检查证据与范围

- 42 段录音均进行了自动转录、音量／削波／停顿检查；成人声音另用辅助分类器排查明显的性别标注冲突。儿童年龄与男女性别感不能仅凭基频或成人分类器认定。
- 原有成人录音没有发现需要大批删除的明确性别错标或大段漏读；专名存在同音字转录差异。声纹相似度只作辅助线索，没有将高相似度直接当作重复声音删除。
- 五个重做声音各生成了两段未出现过的文案（日常对白、正式说明），共 10 段；均走声音复用，保持同一角色样本，没有重新设计。自动转录与输入逐字一致（忽略标点）。
- 101 项 Python 后端测试通过，包括精选样本复用、原定声保留、自定义描述、语言切换、损坏与越界路径拒绝。
- 客户端、模板、素材一致性及引擎样本提取测试通过；全部 UI 回归与真实 Electron 项目回归通过。
- 检查以自动分析与真实模型回归为证据，没有将这些结果表述为真人盲听、精确年龄识别或主观音质认证。童声的年龄感仍需结合实际试听判断。

辅助分析使用本机已有 TTS 声纹编码器、[Qwen3-ASR](https://huggingface.co/mlx-community/Qwen3-ASR-0.6B-4bit) 及 [MIT 授权的成人声音分类器](https://huggingface.co/Alice-Sabrina-Ivy/voice-gender-classifier-onnx-q8-v2)。这些分析模型仅用于本地检查，不随客户端分发；没有使用非商业授权的年龄模型。原始录音、候选、选择记录和检查结果保存在 `.test-data/voice-audit-2026-10-15/`。
