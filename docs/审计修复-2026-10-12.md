## 升级与兼容说明

- 原作品和历史音频保留。旧版遗漏角色/场景信息的音频指纹可能显示为需要重新生成，以避免错误复用；不会删除旧音频。
- 已定声角色的声音设置签名保持兼容。新增长句生成批次信息随项目保存。
- 队列读取旧版快照，并引入增量日志。请正常关闭应用后再升级；不要在生成任务运行时替换程序文件。
- 旧版本遗留的根目录 ZIP 不自动删除，因为不能可靠判断用户是否另作保存；新导出使用专属临时目录。
- 历史上无法确认归属的无 owner 空锁仍保守阻断；不会仅按目录年龄自动删除，以免破坏活进程的互斥。
- Windows 当前自动安装 CPU 组件。有 NVIDIA 显卡不代表该安装配置启用了 CUDA。

## 仍需目标平台验收

本轮在云端 Linux 执行源码、控制器、故障注入和构建测试。Windows 编码测试不等于 Windows 安装包验收，模拟模型不等于真实推理质量或 GPU 性能测试。Mac / Windows 真机、低内存设备、真实模型、录音权限、发行签名与公证仍须单独验证。

跨进程空闲模型重复常驻（R7）仍需服务所有权方案和真实内存验证。简单地在每句后关闭模型会显著降低长项目性能，因此本轮未冒进修改。

公开依赖公告命中不等于已经证实产品可被利用。网站构建链更新至 Vite 6.4.4，并更新兼容传递依赖；开发服务器默认绑定 127.0.0.1。桌面构建依赖 sprintf-js 1.1.3 暂无已发布修复版。qwen-tts 0.1.1 严格锁定 transformers 4.57.3 与 accelerate 1.12.0，cryptography 49 起取消 Intel Mac 支持，因此 Python 大模型依赖不能简单统一升级。本轮保留三平台推理依赖锁，需另做分平台维护与真实模型回归，不能宣称安全验收全部通过。
