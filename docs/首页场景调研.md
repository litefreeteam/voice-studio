# 首页场景调研

调研日期：2026-10-11。

首页的任务是让用户先找到自己想做的内容，再直接进入已有配音流程。场景选择依据主流产品官方页面反复出现的用途与声悦现有能力的交集；这不是市场规模、使用量或热门程度排名。语速、情绪和分段方案是产品设计建议，应以实际试听结果调整。

## 场景与预设

首页完整展示已有 20 个模板。6 个主卡覆盖视频、播客、游戏、儿童内容、教学与长篇阅读，其余 14 个用紧凑卡呈现。名称直接描述用户要完成的任务，避免“泛娱乐”“内容生产”等行业分类词。

| 主卡名称 | 模板 | 预设设计理由 |
| --- | --- | --- |
| 短视频配音 | `knowledge-video` | 清楚有活力的科普男声、自然节奏；适合解说和知识视频，按镜头或句意组织文案。 |
| 双人播客 | `interview-dialogue` | 主持人与嘉宾使用不同声音，每轮单独成句；自然交流比播音腔更符合听感。 |
| 游戏角色配音 | `game-dialogue` | 台词逐句指定人物与情绪，并单独命名；便于试听、重做和接入游戏。 |
| 儿童绘本 | `children-reading` | 温柔旁白与清亮童声区分叙述和角色；每句分开，方便和绘本页面对应。 |
| 讲课与课件 | `course-batch` | 复用讲师声音，按知识点或课件页分段；方便批量生成和单段修改。 |
| 有声书朗读 | `audiobook` | 稳定叙述声、自然节奏；长篇内容按章节或自然段分批制作。 |

其余 14 个紧凑卡：知识微课（`knowledge-lesson`）、企业培训（`training-onboarding`）、操作教程（`tutorial-software`）、英语跟读（`language-lesson`）、考点复习（`exam-review`）、旅行 Vlog（`travel-vlog`）、播客开场（`podcast-intro`）、纪录片旁白（`documentary`）、产品说明（`product-demo`）、带货口播（`ecommerce`）、品牌广告（`brand-ad`）、客服与通知（`service-guide`）、睡前故事（`bedtime-story`）、冥想与放松（`relaxation`）。

慢节奏优先用于儿童绘本、操作教程、英语跟读、纪录片、睡前故事和冥想放松；日常对话、讲课和口播默认自然节奏。双人播客、游戏和绘本使用现有逐句多角色配置；课程和教程使用换行分段配置。双人播客同时匹配“视频与播客”和“角色对白”分类。这里不承诺精确倍速、精确停顿秒数、自动写稿或自动成片。

新闻播报虽然也被多个平台列为用途，本次首页优先展示已有模板，不新增未经验证的场景能力。

## 官方来源

- [ElevenLabs 场景总览](https://elevenlabs.io/use-cases)：视频配音、播客、有声书、游戏角色和演示配音，是跨平台用途交集的主要参考。
- [豆包播客产品介绍](https://docs.volcengine.com/docs/DoubaoVoice/ProductOverview-4?lang=zh)：双人播客、内容解读、儿童教学和故事；支持双人播客与儿童内容的任务设计。
- [火山引擎复刻语音合成](https://docs.volcengine.com/docs/LakeAIService/ReplicaTextToSpeech?lang=zh)：旁白、短视频配音、课程内容、长文本讲解等用途。
- [腾讯云语音合成](https://cloud.tencent.com/product/tts)：有声阅读、客服提示和语音播报；支持朗读与服务提示场景。
- [剪映官网](https://www.jianying.com/)：文本朗读、音色克隆、智能解说和营销成片；支持视频口播与推广内容的需求判断。
- [CapCut / Dreamina 文本转音频](https://dreamina.capcut.com/ai-voice/text-to-audio)：短视频、播客、有声书、故事、广告、教学和角色对白。
- [讯飞智作](https://peiyin.xunfei.cn/)：多风格多语种配音、PPT/文案生成与多场景适配；动态场景列表未完整暴露，因此不据此推断具体场景排名。

## 命名与视觉落地

推荐入口文案“按场景开始创作”，主按钮“开始创作”，预览操作“试听示例”。场景卡展示用户任务、适合制作的内容和已配置的角色/节奏，避免要求用户先理解模型参数。

视觉延续声悦现有的浅色背景、紫色主色与柔和插画。播客用双麦克风，游戏用角色与手柄，绘本用打开的故事书，讲课用课件与黑板，短视频用播放画面，有声书用书与耳机，让卡片图帮助用户辨认用途。背景图保持低对比度，文字和按钮使用前景色保证清晰。
