# README visual assets

- `hero.svg` is the editable, original vector banner. `hero.png` is its 2× raster export, used for consistent rendering across GitHub themes and browsers.
- `home.png`, `project.png`, `voices.png`, and `workspace.png` were captured from the v0.4.8 desktop source on 2026-11-09, using a disposable demo profile and fictional sample text. They show the real Chinese interface, without user projects or private recordings.

The banner uses the project's lavender and mint palette. Product screenshots are shared by both language editions of the README; the English edition explicitly identifies the desktop UI language.
